# Agência Caju — landing page

Site institucional da **Agência Caju**, agência de branding, conteúdo e performance. Página única, responsiva, feita em HTML, CSS e JavaScript puros, sem frameworks nem etapa de build.

## Destaques

- Layout responsivo com imagens específicas para **desktop** e **mobile** (`desktop/` e `mobile/`).
- SEO básico: `meta description`, `keywords` e tags **Open Graph** para compartilhamento em redes sociais.
- Acessibilidade: todas as imagens com texto alternativo.
- Chamadas para ação direto para WhatsApp, Instagram e e-mail.
- Tipografia Poppins (Google Fonts) e identidade visual da marca.

## Estrutura

```
index.html      página completa (HTML + CSS + JS)
img/            logos, elementos da marca e fotos da equipe
desktop/        imagens das seções na versão desktop
mobile/         imagens das seções na versão mobile
```

## Como ver localmente

Abra o `index.html` no navegador. O site está hospedado no **Cloudflare Pages**. Para publicar uma cópia, basta enviar a pasta em *Workers & Pages > Create > Pages* ou ativar o GitHub Pages neste repositório (*Settings > Pages > Branch: main*).
